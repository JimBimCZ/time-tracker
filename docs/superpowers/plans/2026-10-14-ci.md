# CI Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GitHub Actions workflow runs typecheck, lint, build and the e2e smoke suite on every PR and every push to `main`.

**Architecture:** One workflow file with two parallel jobs, `checks` and `e2e`. Both use the same setup steps. The e2e job reuses the existing `pnpm e2e` (Compose infra plus Playwright).

**Tech Stack:** GitHub Actions on `ubuntu-latest`, pnpm 12.8.1 (from `packageManager`), Node 24.20.0, Docker Compose, Playwright 1.63.0.

**Spec:** `docs/superpowers/specs/2026-10-14-ci-design.md`

## Global Constraints

- Pin actions to these commit SHAs, with the version as a trailing comment:
  - `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1` (v7.0.1)
  - `pnpm/action-setup@ea17c68df8912ef543352723c149a84f56e3d413` (v6.1.0)
  - `actions/setup-node@820762786026740c76f36085b0efc47a31fe5020` (v7.0.0)
- Triggers: `pull_request`, and `push` to `main`. Never `pull_request_target`.
- `permissions: contents: read` at the workflow level.
- Node `24.20.0`. Pass no pnpm `version` input; the version comes from `packageManager`.
- Job names are exactly `checks` and `e2e`; branch protection will reference them.
- Keep docs current: add a CI line to `CLAUDE.md` Commands in the same change.

### Task 1: CI workflow

**Files:**
- Create: `.github/workflows/ci.yml`
- Modify: `CLAUDE.md` (Commands section)

**Interfaces:**
- Consumes: the root scripts `typecheck`, `lint` and `e2e`; `pnpm -r build`; `services/*/.env.example`; the e2e config's `CI` behaviour (`forbidOnly`, `github` reporter, `reuseExistingServer: false`).
- Produces: the status checks `checks` and `e2e` on PRs.

- [ ] **Step 1: Write the workflow**

`.github/workflows/ci.yml`:
```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  checks:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: pnpm/action-setup@ea17c68df8912ef543352723c149a84f56e3d413 # v6.1.0
        with:
          cache: true
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 24.20.0
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm -r build

  e2e:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: pnpm/action-setup@ea17c68df8912ef543352723c149a84f56e3d413 # v6.1.0
        with:
          cache: true
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 24.20.0
      - run: pnpm install --frozen-lockfile
      - run: for s in services/*; do cp "$s/.env.example" "$s/.env"; done
      - run: pnpm --filter @tt/e2e exec playwright install --with-deps chromium
      - run: pnpm e2e
      - if: failure()
        run: docker compose logs --no-color
```
