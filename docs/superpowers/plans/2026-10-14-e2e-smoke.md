# E2E Smoke Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pnpm e2e` boots the stack and runs a Playwright suite that proves UI → Kong → service → Postgres/Kafka wiring, Kong's route boundary and its rate-limit plugin.

**Architecture:**
- A new workspace package `e2e/` (`@tt/e2e`).
- Infra comes up through the existing `pnpm infra:up`.
- Playwright's `webServer` array starts the 4 services and the web app with their existing `dev` scripts.
- Tests hit Kong at `:8000` and the web app at `:5173`.

**Tech Stack:** `@playwright/test` 1.63.0 (Chromium only), pnpm workspaces, TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-14-e2e-smoke-design.md`

## Global Constraints

- Pin exact versions: `@playwright/test` `1.63.0`, `@types/node` `24.19.0`, `typescript` `6.0.3`.
- If `pnpm install` fails on an unreviewed install script, decide it in `allowBuilds` in `pnpm-workspace.yaml`. Don't bypass it.
- Kong base URL is `http://localhost:8000`, web is `http://localhost:5173`, and services are on ports 3001–3004 (auth, catalog, tracking, reporting).
- Rate-limit header: `x-ratelimit-limit-minute: 100`, verified against Kong 3.9.2.
- Keep docs current: add `pnpm e2e` to the Commands section of `CLAUDE.md` in the same change.

- [ ] **Step 2: Write the config**

`e2e/playwright.config.ts`:
```ts
import { defineConfig } from '@playwright/test';

const services = [
  ['auth', 3001],
  ['catalog', 3002],
  ['tracking', 3003],
  ['reporting', 3004],
] as const;

// Infra (Postgres, Kafka, Redis, Kong) must already be up: `pnpm e2e` runs `infra:up` first.
const server = (name: string, url: string) => ({
  name,
  command: `pnpm --filter @tt/${name} dev`,
  url,
  reuseExistingServer: !process.env.CI,
  timeout: 120_000,
  gracefulShutdown: { signal: 'SIGTERM' as const, timeout: 5_000 },
});

export default defineConfig({
  testDir: 'tests',
  forbidOnly: !!process.env.CI,
  reporter: process.env.CI ? 'github' : 'list',
  use: { baseURL: 'http://localhost:8000' },
  // A service's /health returns 200 only once its Postgres and Kafka are reachable.
  webServer: [
    ...services.map(([name, port]) => server(name, `http://localhost:${port}/health`)),
    server('web', 'http://localhost:5173'),
  ],
});
```

- [ ] **Step 3: Write the suite**

`e2e/tests/stack.spec.ts`:
```ts
import { expect, test } from '@playwright/test';

for (const svc of ['auth', 'catalog', 'tracking', 'reporting']) {
  test(`${svc} is healthy through Kong`, async ({ request }) => {
    const res = await request.get(`/${svc}/health`);
    expect(res.status()).toBe(200);
    expect(await res.json()).toEqual({ db: 'ok', kafka: 'ok' });
  });
}

test('Kong does not match look-alike prefixes', async ({ request }) => {
  const res = await request.get('/authx/health');
  expect(res.status()).toBe(404);
});

test('Kong rate limiting is active', async ({ request }) => {
  const res = await request.get('/auth/health');
  expect(res.headers()['x-ratelimit-limit-minute']).toBe('100');
});

test('web app renders', async ({ page }) => {
  await page.goto('http://localhost:5173');
  await expect(page.getByRole('heading', { name: 'Time tracker' })).toBeVisible();
});
```
